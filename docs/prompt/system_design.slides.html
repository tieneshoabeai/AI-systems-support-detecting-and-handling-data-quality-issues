Đăng nhập & xoay vòng phiên

POST /auth/login

  • 1Tìm user, kiểm tra bị khóa
  • 2bcrypt so khớp mật khẩu
  • !Sai → cùng một câu "Email hoặc mật khẩu không chính xác"
  • 3Access token 15 phút · refresh 7 ngày
  • 4Lưu phiên dạng SHA-256(refresh)

POST /auth/refresh

  • 1Tìm phiên theo hash token
  • 2Còn hiệu lực → thu hồi phiên cũ, cấp cặp token mới
  • !Token đã bị thu hồi mà vẫn gửi lên → thu hồi toàn bộ phiên của user
