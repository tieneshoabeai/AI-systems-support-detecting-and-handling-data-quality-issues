06 · Kiến trúc

Modular Monolith bên ngoài · Hexagonal hoặc Simple bên trong

Modular Monolith — 1 lần deploygiao tiếp chỉ qua index.ts
HEX · 7 có ≥1 trong 4 tiêu chí: invariant nghiệp vụ · transaction · RBAC 3 tầng · tích hợp ngoài dễ lỗi (AI, S3, SMTP)
SIMPLE · 6 CRUD / đọc số liệu đơn giản → file phẳng, ít nghi thức
main.ts HTTP API
worker.ts AI job · PDF job
shared/ — lỗi miền · phân trang keyset · guard/CASL · storage (dùng chung, không import ngược vào modules)
4 tầng trong module Hexagonal — phụ thuộc chỉ hướng vào domain
presentationcontrollers · dtos
Nhận HTTP, validate bằng Zod, gọi handler. Không chứa nghiệp vụ. Ví dụ analysis.controller.ts chỉ 1 dòng gọi RunAnalysisHandler.
applicationcommands · queries · ports
Điều phối 1 use case: mở transaction, gọi port, ghi dữ liệu. Mỗi use case một file *.handler.ts. Không import mongoose / aws / infrastructure (CA2).
domainentities · VO · ports
Quy tắc nghiệp vụ thuần: entity, value-object (*.vo.ts), interface port (*.port.ts), hàm tính DQ. Không biết NestJS hay Mongoose (CA1).
infrastructurepersistence · adapters
Cài đặt port: Mongoose *.schema.ts + *.repository.ts + *.mapper.ts; adapter S3, Ollama, bcrypt, Google OAuth.
Quy ước chung (kiểm tự động)
  • MM2: module khác chỉ import qua index.ts, cấm import sâu ../datasets/domain/…
  • CA1 / CA2: domain, application không import infra — ESLint mức error
  • CA5: shared/ không import modules/ — mức warn (còn 1 vi phạm đã biết)
  • Cấm any · 5 test kiến trúc chạy bằng pnpm test:arch
