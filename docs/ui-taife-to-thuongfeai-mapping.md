# Bản đồ UI TaiFE → nghiệp vụ ThuongFEAI

> Tài liệu chuẩn bị thay lớp trình bày TaiFE vào ThuongFEAI. Route, nguồn dữ liệu, API, quyền, mutation, xử lý lỗi và offline trong tài liệu này lấy theo mã nguồn hiện tại của ThuongFEAI. UI TaiFE chỉ được xem là nguồn tham khảo bố cục và cách trình bày.

## Phạm vi và quy ước

- ThuongFEAI được kiểm tra ở working tree hiện tại, bao gồm các thay đổi local chưa commit trong auth, API target và offline. Không được ghi đè hoặc bỏ các phần đó khi chuyển UI.
- Các route canonical là `/login`, `/management/...` và `/processing/...`; route/hash `/preview/...` cũ chỉ được redirect tương thích.
- UI được đổi: cấu trúc DOM, bố cục, thứ tự/nhóm nội dung, nhãn hiển thị, typography, màu, icon, spacing, responsive, animation, cards, charts, dialogs/popovers/toasts và cách trình bày loading/empty/error.
- Hành vi phải giữ: route, guard, provider, store/service, request/API payload, quyền, optimistic update/rollback, lưu trạng thái, offline queue/cache, upload drafts, validation, polling, download và accessibility semantics.
- Component trình bày mới nhận dữ liệu/trạng thái/callback qua props hoặc context. Không import `previewMockStore` hoặc hook nghiệp vụ của TaiFE vào màn hình dùng thật.

## Cross-cutting action contract

| Action class | ThuongFEAI point of truth | UI replacement rule |
| --- | --- | --- |
| Navigation | `services/navigation/application-route.ts`; `session.openSection`; React Router | Use canonical paths. Legacy preview route only redirects. Project step URLs redirect to project workspace. |
| Read / reload | `ManagementDataProvider`, `ProcessingDataProvider`, `ManagementStore`; `ManagementLoadingContext`, `ProcessingDataContext` | Render supplied state; use existing retry/reload callbacks. Avoid parallel duplicate API reads in presentation components. |
| Management mutation | `use-management-session` wraps the current store and mutation result/error behavior | Call session callbacks. Do not access `previewMockStore` or synthesize successful local state. |
| Project/data mutation | `ManagementStore` methods (`createProject`, `uploadDataset`, `completeProject`, dataset operations) and typed services | Preserve capability checks, confirmation, queue/defer options and refresh/invalidation behavior. |
| Analysis / Feedback | `AnalysisService` via store/context; feedback API scopes | Keep run/finding scope IDs, validation and pagination. Evidence samples require a separate read API before UI can show them. |
| Appearance | ThuongFEAI color scheme and appearance provider | Reuse existing selected/resolved theme state; TaiFE CSS must consume tokens/state, not create a competing theme owner. |
| Offline | `AppRuntime.localData`, `offlineWrites`, upload draft repository, API target manager | Keep cache namespace, account scoping, queue reconciliation and connectivity notices. UI may restyle the notice, not bypass it. |

## Menu, dialog và tab contract

- Menu tài nguyên được định nghĩa tập trung trong [resource-menu.ts](../src/frontend/src/hooks/resource/resource-menu.ts); nút ⋯, menu chuột phải và dropdown thao tác phải dùng chung descriptor. Workspace: thông tin, thành viên, xóa. Project list: mở, thông tin, đổi tên, xóa. Project Workspace dataset menu: thông tin project, thành viên, xóa. Không tự thêm các mục “archive/duplicate/status” từ mock/ảnh cũ nếu ThuongFEAI hiện không cấp action.
- `session.run` là dispatcher cho resource menu: open workspace ghi `touchWorkspace` rồi điều hướng; open project kiểm tra project còn tồn tại, chọn project và đi đúng route; `ws-info/ws-members/pj-members/info` mở surface tương ứng; rename/remove mở dialog; favorite gọi store. Giữ confirm dialog, disabled hint, toast/error và hành vi focus.
- Tab management hiện là state trình bày (ví dụ grid/list, filter tabs); đổi tab không được thay API capability. Tab admin Users/Issues đổi dữ liệu detail được chọn. Tab notifications/report lọc list hiện có; giữ URL/detail semantics nếu đã có.
- Mỗi dialog phải giữ submit/cancel/close, busy-lock, validation, `role=alert`/status, focus trap/restore và dialog/alertdialog semantics. Thay visual surface không được bỏ đường đóng bằng Escape/scrim nếu component hiện hỗ trợ.

## Quyền và khả năng theo dữ liệu hiện hành

- Route Management/Processing nằm sau `ProtectedRoute`; login return target cần được giữ khi phiên chưa kết thúc do logout.
- Admin navigation/panel chỉ có khi store cấp `adminService` cho role admin. Không suy luận quyền quản trị từ tên hoặc nhãn giao diện.
- Workspace owner capability được biểu diễn qua `workspace.canManage`; dùng để sửa workspace/thành viên/tạo project và resource access.
- Project capabilities gồm `canManage`, `canDelete`, `canUpload`, `canUpdateDatasetMetadata`, `canComplete`. Dữ liệu quyền có thể đang `permissionsPending`; trong trạng thái này khóa thao tác phụ thuộc quyền.
- API mode không hỗ trợ mọi thao tác mà mock UI cũ từng cho phép. Ví dụ xóa notification đang disabled; organization profile bị khóa; role Admin không được thêm vào project trong API mode. Giữ nguyên khả năng thật của store/backend.
- Backend là nơi quyết định cuối cùng. UI disable/ẩn để hướng dẫn đúng; error HTTP vẫn cần hiển thị nếu quyền thay đổi giữa lúc tải và mutation.

## Phân loại khi chuyển component

### Có thể chuyển như presentation

- TaiFE `views/preview` shell/layout/CSS/theme treatment, card/table/dialog surfaces, icon artwork, spacing/type/color, responsive behavior, decorative illustration, visual grouping and copy **sau khi review nội dung**.
- TaiFE loading/empty/error visual pattern nếu vẫn nhận phase/message/retry từ ThuongFEAI và giữ semantic role/focus behavior.
- TaiFE component không chứa API, mock store, mock IDs/data hoặc mutation nội bộ.

### Không chép vào ThuongFEAI như một khối

- TaiFE preview session/hooks/mock store, preview presentation-data as data source, route adapter/legacy behavior, fixture assumptions, sample/demo interactions.
- TaiFE `ApplicationFrame` nếu thay provider/auth/offline ownership hiện tại của ThuongFEAI.
- Bất kỳ view nào gọi trực tiếp `previewMockStore`, tự sinh dữ liệu thành công, giả permission, hoặc bỏ callback/API hiện tại.

### Cách nối chuẩn cho component mới

1. Container ThuongFEAI lấy state từ `usePreviewSession`/`useManagementStore`/processing context hiện tại.
2. Container truyền giá trị hiển thị và callback qua props/context cho presentation component.
3. Presentation component chỉ quản lý state tạm tại chỗ (menu mở, tab hiển thị, disclosure, field draft); khi submit gọi callback do container truyền.
4. Loading/error/permission/disabled state đến từ provider/store/service hoặc local mutation pending hiện hữu.
5. Sau API mutation, dùng snapshot/refresh/invalidation do store cung cấp; không tự sửa mock state hoặc hiển thị success sớm.
