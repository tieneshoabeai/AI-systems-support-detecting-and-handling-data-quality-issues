2 • Kỹ thuật

Hexagonal 3 tầng + Zero-Any

Luật tách tầng

  • Domain: entity, VO, event, util, port Symbol — thuần TS
  • Application: chỉ @Inject(PORT), input interface thuần
  • Infrastructure: controller, Zod DTO, schema, repo, mapper, adapter, gateway
  • Wiring: { provide: PORT, useExisting: Repo }

Chất lượng mã

  • Cấm as any / : any toàn src/scripts/test
  • Mapper gõ chặt Parameters<typeof find>
  • zero-any.spec.ts quét từng dòng, vi phạm fail CI
  • 16 ports Symbol + AiInferencePort, 12 controllers, 1 gateway
Domain (entity/VO/event/util/port Symbol) ↑ phụ thuộc ngược qua port Application (11 services + 2 workers, chỉ @Inject PORT) ↑ gọi qua port Infrastructure (controller / DTO-Zod / schema / repo / mapper / adapter / gateway) ↑ wiring NestJS Module ({ provide: PORT_SYMBOL, useExisting: Concrete })
2 • Kỹ thuật (tiếp)

Envelope • Phân trang • Streaming

Request → Response

  • ZodValidationPipe safeParse → 400 {field,message,code}
  • OK: {success:true,data} (TransformInterceptor)
  • Lỗi: {success:false,error:{code,message,timestamp,path}}
  • Trùng key 11000 → 409 DUPLICATE_RESOURCE
  • CursorCodec base64url: {row_index}, {createdAt,id}

Ingestion 3 nhánh song song

  • PassThrough: SHA-256 + upload R2/local + parse CSV
  • Không nạp RAM, không file tạm, vượt 50MB hủy cả 3
  • Schema 100 dòng đầu, bulk 5000, props c0..cN
  • 1 project = 1 dataset; lỗi → rollback + FAILED

Lưới ảo keyset + Auth đa phiên

Lọc dataset_id + row_index > cursor, lấy limit+1 biết hasMore; 14 toán tử → $regex/$gt/$in/$exists; aggregate histogram 10 buckets. Login: bcrypt → refresh thô → SHA-256 → detectDevice → session(ip+UA) → access {sub,email,role,sessionId}. Issues khóa lạc quan expectedVersion.

3 • AI (tiếp)

Thuật toán Domain + RAG Few-Shot

DQ • Tương quan • VIF

  • DQ-01 thiếu, 02 trùng fingerprint, 03 sai kiểu, 04 outlier IQR + modified z-score (n≥4)
  • 0/false/'NA' không tính là thiếu
  • Pearson/Spearman + n/missing/computable/reason
  • VIF nghịch đảo ml-matrix, cờ ok/review/high
  • Evidence ≤20/cột, summary top 50

RAG học từ feedback (T1)

  • Tối đa 50.000 mẫu FIFO, TTL 180 ngày
  • trust ≥ 0.6, topK 5, cosine thuần trong Mongo
  • 5 nhãn → 3 nhãn kho; 3 nhãn bắt buộc reason
  • Trùng → update trust, mới → save + enforce cap
  • Lỗi RAG trả rỗng, không chặn AI

Worker báo cáo

POST /report chỉ tạo job pending + {reportId, pollUrl} → ReportWorker poll 10s → đọc project_save mới nhất → upload reports/<project>/<report>.txt → succeeded{storageKey,fileSizeBytes} → GET file trả 202 khi chưa xong, stream text/plain khi xong.
