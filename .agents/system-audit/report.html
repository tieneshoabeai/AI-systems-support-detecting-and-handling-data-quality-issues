Giá trị trống phone/bio → null.

V · Technical Workflow · 25

HTTP request và response

Giữ transport hiện có; generic request<T> không tự kiểm tra schema runtime.

Request

UI → hook → service/store → Axios.
Public/session, Bearer và timeout.
Signal gắn lifecycle của phiên.

Response

204 → undefined; Blob → trực tiếp.
JSON unwrap → guards/mapper.
Revision/disposed check → publish.

Đã sửa / còn thiếu

GET /health resolve origin root.
Members có cursor loop guard.
DTO validation chưa phủ toàn bộ.
Không tự retry mutation thất bại.

Nguồn: audit/frontend-api-revalidation.md §2–3; 05-technical-workflow.md cập nhật.
